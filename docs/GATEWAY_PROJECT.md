# Village gateway: an optional player-led shared project

S5 continuation, 2026-10-30. Book of Creation -> Projects adds one bounded, untimed experiment connecting the existing timber relays, player/creature construction and villager structure use.

## What the player does

Choose Begin project at an unfinished main yard. Empty yards can select the known arch form; partial arches may continue. A completed yard or a partial different form is refused with a notice. No existing layout, actor task or save is reset. Mark yard reuses the private 45-second activity beacon; End project stops recording without removing the work. Projects uses the eighth existing-sized rounded-rectangle section slot, an existing atlas icon, and the existing primary/secondary Book actions. God Tools retain their circular controls.

Record three wood arriving through a new native villager or creature timber relay. Snap part of the arch while the creature watches; its existing shared-build invitation can attract it to place a different piece of a known form. Finish the arch together, then leave room for a villager to walk through. For the spanning beam, aim at a pillar's inner top rim using the existing pointer span affordance. A free, uninjured villager's structure chooser can revisit a ready project even if it has seen an arch before. Existing safety, social/family ownership and shelter checks still apply; the project does not order movement or guarantee immediate participation.

The timber milestone stocks the village's real stores. It does not consume that wood or claim that reusable toy blocks were manufactured from it. This is an authored shared-play/construction experiment, not a new production chain or automatic village-road planner. Food/water remain deprioritized and development energy remains unlimited.

## Evidence and lifecycle

Begin records current relay and placement receipt baselines. Earlier supply, old snaps, anonymous staging, other yards and merely opening the Book cannot satisfy the project. Actual positive relay deposits advance supply once per relay receipt; canceled cargo does not. Confirmed main-yard arch placements maintain disjoint bounded player/creature piece masks. One physical piece cannot count for both actors. Villager replacement of a piece clears its player/creature attribution.

At 4 Hz while active, existing attached recipe geometry trims the masks; held, removed, fallen, changed-form or non-pattern pieces do not retain credit. Native use completion validates the current geometry again. Only the existing villager walkthrough/use completion callback can finish the project, after three stored wood and both current contributors. Snaps alone do not finish it. Completion is historical after being recorded, so subsequent damage does not erase an earned result. No extra trust, faith, energy, free stock or creature training is minted by the project layer.

Progress, receipt cursors, the two piece masks, attempt/completion counts and final visitor/time persist in one bounded optional GatewayProject record. Native Save/Load preserves partial geometry through the existing construction save. Restore does not replay placement receipts or erase masks mid-reconstruction. Old/default saves remain valid. Pause blocks begin/end, progress and completion; Book reads remain pure. Ending retains the world and recorded progress, while beginning a later attempt establishes fresh baselines. Starting another project never demolishes a finished arch.

Exactly one project completion survives native completed Save/Load. Replay refusal preserves the completed arch.

The timber test accepts optional fixture callbacks so the end-to-end project check can reuse actual cargo/harvest/handoff/deposit validation rather than fake a supply counter. Project tests isolate actor positions and competing opportunities for repeatability. They do not establish population-wide recruitment rate, easy beam targeting or Quest comfort/performance. The private beacon is the existing player aid, not new world primitive artwork.

Book model/runtime layout and input checks and the related construction/resource/relay regressions are run alongside the increment. Project pages and the eight-button index are rendered for visual inspection with a staged display fixture. Physical headset validation remains deferred, no APK is built, and the original user save and XR startup flags are restored after testing.
